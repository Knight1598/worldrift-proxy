# ระบบติดตามสถานะ แบตเตอรี่ / รถส่งซ่อม

ระบบให้สาขาเช็คเองว่าของที่ส่งมาอยู่ขั้นตอนไหน โดยไม่ต้องโทรถาม
และพนักงานที่ดูแลอัปเดตสถานะได้จากมือถือ

หน้าเดียวมี **2 แท็บ** ใช้ลิงก์ชุดเดียวกัน กุญแจแอดมินตัวเดียวกัน
- **🔋 แบตเตอรี่** — ติดตามการกระตุ้นแบต
- **🔧 รถส่งซ่อม** — ติดตามงานซ่อม บันทึกด้วย **เลข JOB** และ **เลขที่สัญญา**

**แยกขาดจากระบบบันทึกส่งอะไหล่** — ใช้ไฟล์ Google Sheet และโปรเจกต์ Apps Script ของตัวเอง
ลิงก์ที่ส่งให้สาขาจึงแตะข้อมูลการส่งของหรือราคาไม่ได้เลย

**สถานะงานแบต 5 ขั้น** (เรียงตามลำดับงาน):

```
รอต่อคิวกระตุ้น → กำลังกระตุ้น → กระตุ้นเสร็จแล้ว → รอจัดส่ง → จัดส่งแล้ว
```

> ขั้น **จัดส่งแล้ว** ต้องมี **ใบบันทึกการจัดส่ง** กำกับ (รูปหลักฐาน + ชื่อคนที่มารับ)
> ดูหัวข้อ "ใบบันทึกการจัดส่ง" ด้านล่าง

**สถานะงานซ่อม 4 ขั้น**:

```
รอซ่อม → รออะไหล่ → กำลังซ่อม → ซ่อมเสร็จแล้ว
```

> เรียงจาก "ยังไม่ได้ลงมือ → ติดของ → กำลังทำ → เสร็จ" อยากสลับลำดับให้แก้
> ตัวแปร `REPAIR_STATUSES` ที่ต้นไฟล์ `Code.gs` ได้เลย (แถบสรุปด้านบนจะเรียงตามนั้น)

---

## ขั้นตอนที่ 1 — สร้างชีตและวางโค้ด

1. สร้าง **Google Sheet ใหม่** (คนละไฟล์กับของระบบส่งอะไหล่) ตั้งชื่อเช่น "ติดตามสถานะแบตเตอรี่"
2. เมนู **ส่วนขยาย → Apps Script**
3. ก็อปวาง **2 ไฟล์**

   | ไฟล์ในโฟลเดอร์นี้ | ทำยังไงใน Apps Script |
   |---|---|
   | `Code.gs` | มีไฟล์ `Code.gs` อยู่แล้ว — เลือกทั้งหมด (Ctrl+A) → ลบ → วางเนื้อหาไฟล์นี้ทับ |
   | `Battery.html` | กด **+** ข้าง Files → **HTML** → ตั้งชื่อ `Battery` (ไม่ต้องพิมพ์ `.html`) แล้ววาง |

   > ชื่อไฟล์ HTML ต้องเป็น `Battery` เป๊ะ ๆ เพราะโค้ดเรียกไฟล์นี้ตามชื่อ

4. กด **Ctrl+S**

---

## ขั้นตอนที่ 2 — สร้างโครงสร้างชีต

เลือกฟังก์ชัน **`setupSheets`** จากดรอปดาวน์ด้านบน แล้วกด **▶ เรียกใช้**
(ครั้งแรกจะขอสิทธิ์ → ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โครงการ (ไม่ปลอดภัย) → อนุญาต)

จะได้ 3 แท็บ:

| แท็บ | เก็บอะไร |
|---|---|
| `Branches` | รายชื่อสาขา **เติมมาให้แล้ว 166 สาขา** (รหัส / ชื่อ / เขต) ใส่ `FALSE` ช่อง `active` เพื่อซ่อนสาขาที่เลิกใช้ |
| `Batteries` | รายการแบตแต่ละล็อต ระบบเขียนให้เองเวลาใช้งานผ่านหน้าเว็บ |
| `Repairs` | รายการรถส่งซ่อม (เลข JOB / เลขที่สัญญา / รุ่นรถ / สาขา / สถานะ) ระบบเขียนให้เอง |

ชีต `Batteries` มีคอลัมน์ของใบจัดส่งเพิ่มมาด้วย: `deliveredAt` `receiver` `deliveryNote`
`deliveryPhotoId` — ระบบเขียนให้เองตอนบันทึกใบจัดส่ง ไม่ต้องกรอกเอง

---

## ขั้นตอนที่ 3 — Deploy เว็บแอป

1. **Deploy → New deployment** → ชนิด **Web app**
2. **Execute as**: `Me` / **Who has access**: `Anyone`
3. กด **Deploy**

---

## ขั้นตอนที่ 4 — เอาลิงก์ไปแจก

รันฟังก์ชัน **`showBatteryLinks`** แล้วดูที่ "บันทึกการดำเนินการ" จะได้ลิงก์ 3 แบบ

| ลิงก์ | ให้ใคร | ทำอะไรได้ |
|---|---|---|
| `.../exec` | สาขาทั่วไป | ดูสถานะทุกสาขา ทั้งงานแบตและงานซ่อม ค้นหา กรอง — **แก้ไขอะไรไม่ได้** |
| `.../exec?branch=คง` | สาขาคง | เหมือนข้างบน แต่ล็อกให้เห็นเฉพาะของสาขาตัวเอง (ล็อกทั้งสองแท็บ) |
| `.../exec?key=xxxx` | พนักงานที่ดูแล | เพิ่มรายการ แก้ไข เปลี่ยนสถานะ ได้ทั้งสองแท็บ |

### เข้าโหมดแอดมิน

**กดปุ่มกุญแจ 🔑 ที่มุมขวาบนของหน้า** แล้วกรอกรหัส — ปุ่มแอดมินจะโผล่มาทันทีทั้งสองแท็บ
พอเข้าแล้วปุ่มจะเปลี่ยนเป็น 🔓 กดอีกทีเพื่อออกจากโหมดแอดมิน

เครื่องนั้นจะจำรหัสไว้ให้ ไม่ต้องกรอกซ้ำทุกครั้ง — **ถ้าใช้เครื่องร่วมกับคนอื่น ควรกดออกทุกครั้ง**

**รหัสอยู่ที่ตัวแปร `ADMIN_CODE` บรรทัดต้น ๆ ของ `Code.gs`** แก้ได้ที่บรรทัดนั้นบรรทัดเดียว
เปลี่ยนแล้ว Deploy เวอร์ชันใหม่ รหัสเดิมจะใช้ไม่ได้ทันที

> รหัสสั้น ๆ เดาได้ไม่ยาก และตัวรหัสอยู่ในไฟล์โค้ด ใครเปิดโปรเจกต์ Apps Script
> หรือ repo นี้ได้ก็เห็น ถ้าวันไหนอยากให้แน่นขึ้น ตั้งเป็นรหัสที่ยาวกว่านี้
> หรือปล่อย `ADMIN_CODE = ''` แล้วระบบจะออกกุญแจสุ่ม 16 หลักให้เอง
> (ดูกุญแจได้จาก `showBatteryLinks` และเก็บไว้ใน Script Properties ไม่อยู่ในโค้ด)

> ยังใช้ลิงก์ `?key=` แบบเดิมได้อยู่ — **แต่อย่าส่งลิงก์นั้นให้สาขา**

### ทำไมถึงเป็น "ดูอย่างเดียว" จริง ๆ

การซ่อนปุ่มบนหน้าเว็บอย่างเดียวไม่พอ เพราะใครก็เรียกฟังก์ชันฝั่งเซิร์ฟเวอร์จากคอนโซล
เบราว์เซอร์ได้ ระบบนี้จึง **ตรวจกุญแจที่ฝั่งเซิร์ฟเวอร์ทุกครั้งที่มีการเขียนข้อมูล**
คนที่เปิดลิงก์ธรรมดา ต่อให้พยายามยิงคำสั่งแก้ข้อมูลก็จะโดนปฏิเสธ

## การใช้งานประจำวัน

**แอดมิน** (เปิดลิงก์ที่มี key):
- กด **"+ เพิ่มรายการแบตเตอรี่"** → เลือกสาขา ใส่วันที่ **เลข อล.** และสถานะ
  (สามอย่างนี้ใช้ร่วมกันทั้งชุด) แล้วกรอกแบตทีละก้อนด้านล่าง
- แบตหลายก้อนที่มากับ อล. ใบเดียวกัน กด **"+ เพิ่มแบตอีกก้อน"** ใส่ต่อได้เลย
  กดบันทึกครั้งเดียวได้เลขที่รายการแยกให้ทุกก้อน
- พองานเดินหน้า แค่เปลี่ยนช่องสถานะในการ์ดของรายการนั้น **การ์ดจะอัปเดตตรงนั้นเลย**
  ไม่โหลดรายการใหม่ทั้งชุด (ป้ายสถานะ สี และตัวเลขในแถบสรุปขยับตามให้ทันที)

**แอดมิน — แท็บรถส่งซ่อม**:
- กด **"+ เพิ่มรายการรถส่งซ่อม"** → เลือก **สาขา** (บังคับ) ใส่เลข JOB เลขที่สัญญา รุ่นรถ → บันทึก
- **เลข JOB ใส่ทีหลังได้** รับรถเข้ามาก่อนแล้วค่อยเปิด JOB ก็บันทึกไว้ได้เลย
  (มากกว่าหนึ่งคันที่ยังไม่มีเลข JOB ก็ไม่ถูกมองว่าซ้ำกัน)
- **ถ้าใส่เลข JOB แล้ว ห้ามซ้ำ** ระบบจะบอกว่าไปชนกับรายการไหน จะได้ไม่ตามงานผิดคัน
- หัวการ์ดโชว์ **สาขา (เขต)** ส่วนเลข JOB / เลขที่สัญญา / รุ่นรถ อยู่บรรทัดรายละเอียด
- ช่องหมายเหตุใส่ทะเบียน อาการ หรืออะไหล่ที่รออยู่ได้
- เปลี่ยนสถานะจากช่องในการ์ดได้เลย การ์ดอัปเดตตรงนั้น ไม่โหลดรายการใหม่ทั้งชุด

**แก้ไข / ลบ ทำในการ์ดเลย** (ทั้งสองแท็บ)
- กด **"✏️ แก้ไข"** บนการ์ด → แผงแก้ไขกางอยู่ในการ์ดนั้น ไม่เด้งไปฟอร์มบนสุด
  แก้เสร็จกด **"บันทึกการแก้ไข"** หรือ **"ยกเลิก"** เพื่อปิดแผง
- กด **"🗑️ ลบ"** → ถามยืนยันก่อน แล้วลบทั้งแถวออกจากชีต (**ลบแล้วเอากลับไม่ได้**)
- ฟอร์มบนสุดเหลือหน้าที่เดียวคือ **เพิ่มรายการใหม่**

**ช่องเลือกสาขา — พิมพ์รหัสสาขาได้**
ทุกช่องที่เลือกสาขา (ทั้งฟอร์มบันทึกและช่องกรอง ทั้งสองแท็บ) เป็นช่องพิมพ์ค้นหา
**พิมพ์รหัสสาขา เช่น `0132` แล้วสาขานั้นจะเด้งขึ้นมาให้กดเลือก** หรือจะพิมพ์ชื่อสาขาก็ได้
ในรายการที่เด้งขึ้นมาจะบอกรหัสและเขตของสาขานั้นกำกับไว้ด้วย

รหัสมาจากคอลัมน์ `branchCode` ในชีต `Branches` — แก้รหัสในชีตได้เลย
(ระบบแคชไว้ 5 นาที ถ้าแก้แล้วยังไม่ขึ้น รอสักครู่หรือรัน `setupSheets()` เพื่อล้างแคช)

### ใบบันทึกการจัดส่ง

พอแบตถึงมือคนรับ **แอดมิน**เปิดใบจัดส่งได้ 2 ทาง — กดปุ่ม **"📦 บันทึกการจัดส่ง"** บนการ์ด
หรือเลือกสถานะ **"จัดส่งแล้ว"** จากช่องสถานะ (ระบบจะพาไปกรอกใบให้ ไม่เปลี่ยนสถานะลอย ๆ)

ขั้นตอนในใบ:
1. **ถ่ายรูป** หรือ **เลือกรูป** หลักฐานการจัดส่ง (บังคับ ต้องมีรูป)
2. ใส่ **ชื่อคนที่มารับ** (บังคับ)
3. ใส่รายละเอียดการจัดส่ง เช่น ส่งกับรถรอบไหน ฝากไว้ที่ไหน
4. กดบันทึก → **สถานะกลายเป็น "จัดส่งแล้ว" ให้เอง** แล้วเด้งกลับไปที่รายงาน

**สาขาเปิดดูใบจัดส่งได้ แต่แก้ไม่ได้** — บนการ์ดของรายการนั้นจะมีกล่อง 📦 บอกชื่อผู้มารับ
วันเวลาที่จัดส่ง รายละเอียด และลิงก์ **"📎 ดูรูปหลักฐานการจัดส่ง"**

- รูปเก็บในโฟลเดอร์ **"หลักฐานการจัดส่งแบตเตอรี่"** ใน Google Drive ของบัญชีที่ deploy
  ตัวไฟล์**ไม่ได้แชร์เป็นสาธารณะ** — กดดูรูปแล้วเว็บแอปเป็นคนดึงมาแสดงให้
- แก้ใบเดิมได้ (ปุ่มจะเปลี่ยนเป็น **"📦 แก้ใบจัดส่ง"**) **ไม่แนบรูปใหม่ = รูปเดิมยังอยู่**
- ค้นหาด้วยชื่อคนที่มารับได้จากช่องค้นหา

> **สิทธิ์ Drive**: ฟีเจอร์นี้ใช้ Google Drive จึงต้องอนุญาตสิทธิ์เพิ่มตอนรันครั้งแรก
> หลังวางโค้ดใหม่ (จะมีหน้าขอสิทธิ์เด้งขึ้นมาอีกรอบ ให้กดอนุญาตตามเดิม)

**สาขา** (เปิดลิงก์ธรรมดา):
- ด้านบนมีแถบสรุปว่าตอนนี้มีกี่รายการอยู่ในแต่ละขั้น
- แท็บแบต: ค้นด้วยเลขที่รายการ อล. ซีเรียล รุ่น หมายเหตุ หรือชื่อคนที่มารับ
- รายการที่จัดส่งแล้วจะมีกล่องใบจัดส่งพร้อมลิงก์ดูรูปหลักฐาน (ดูได้ แก้ไม่ได้)
- แท็บรถส่งซ่อม: ค้นด้วย **เลข JOB** หรือ **เลขที่สัญญา** รุ่นรถ เลขที่รายการ หรือหมายเหตุ
- ทั้งสองแท็บกรองตามสาขา/สถานะได้ (ช่องสาขาพิมพ์รหัสสาขาได้)

ข้อมูลอยู่ในชีต `Batteries` กับ `Repairs` เปิดแก้จากในชีตโดยตรงก็ได้

## ฟังก์ชันที่รันเองได้จาก Apps Script

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupSheets()` | สร้าง/ซ่อมโครงสร้างชีต พร้อมรายชื่อสาขา (รันซ้ำได้ ไม่ลบข้อมูลเดิม) |
| `showBatteryLinks()` | ดูลิงก์ทั้ง 3 แบบสำหรับเอาไปแจก |
| `checkSetup()` | ตรวจว่าชีตครบไหม และดูกุญแจแอดมินปัจจุบัน |
| `debugBatteries()` | ใช้ตอนข้อมูลอยู่ในชีตแต่หน้าเว็บไม่ขึ้น — บอกว่าเซิร์ฟเวอร์อ่านอะไรได้บ้าง (รายงานทั้งงานแบตและงานซ่อม) |

เมื่อสคริปต์ผูกกับชีต จะมีเมนู **"ระบบติดตามสถานะ"** บนแถบเมนูของชีตให้เรียกฟังก์ชันพวกนี้ได้เลย
(ถ้าเมนูไม่ขึ้น ให้รีเฟรชหน้าชีตหนึ่งครั้ง)

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น "ไม่พบชีต ..." | ยังไม่ได้รัน `setupSheets()` |
| ดรอปดาวน์ฟังก์ชันเห็นแค่ `myFunction` | โค้ดวางไม่ครบ ลองลบทั้งไฟล์แล้ววางใหม่ จากนั้น Ctrl+S |
| แก้โค้ดแล้วเว็บยังเป็นของเดิม | ต้อง **Deploy → Manage deployments → ดินสอ → Version: New version** ทุกครั้ง |
| เพิ่ม/แก้สาขาในชีตแล้วยังไม่ขึ้น | ระบบแคชรายชื่อสาขาไว้ 5 นาที รอสักครู่ หรือรัน `setupSheets()` เพื่อล้างแคช |
| ไม่มีปุ่มบันทึกการจัดส่ง / ไม่เห็นสถานะ "จัดส่งแล้ว" | ยังไม่ได้รัน `setupSheets()` หลังอัปเดตโค้ด แล้วต้อง Deploy เวอร์ชันใหม่ด้วย |
| กดบันทึกใบจัดส่งแล้วขึ้นว่าไม่มีสิทธิ์ Drive | รัน `setupSheets()` จาก Apps Script หนึ่งครั้งเพื่อให้หน้าขอสิทธิ์เด้งขึ้นมา แล้วกดอนุญาต |
| ไม่เห็นแท็บรถส่งซ่อม / กดแล้วขึ้นว่าไม่พบชีต Repairs | ยังไม่ได้รัน `setupSheets()` หลังอัปเดตโค้ด แล้วต้อง Deploy เวอร์ชันใหม่ด้วย |
| บันทึกแล้วข้อมูลเข้าชีต แต่หน้าเว็บไม่ขึ้น | รัน `setupSheets()` หนึ่งครั้ง แล้ว Deploy → Manage deployments → **Version: New version** ถ้ายังไม่ขึ้น รัน `debugBatteries()` แล้วดูบันทึกการดำเนินการ |
| หน้าเว็บขึ้นว่า "ไม่พบสาขา ..." บนหัวเรื่อง | ลิงก์มี `?branch=` ที่สะกดชื่อสาขาไม่ตรงกับในชีต ระบบจะแสดงทุกสาขาแทน |
| ข้อมูลในการ์ดเลื่อนช่อง (ชื่อสาขาไปโผล่ช่องรุ่นรถ ฯลฯ) | แก้แล้วในเวอร์ชันนี้ — ระบบอ่านชีตตามชื่อหัวตารางแล้ว ไม่ใช่ตามตำแหน่ง วางโค้ดใหม่แล้วรัน `setupSheets()` เพื่อเติมคอลัมน์ที่ยังขาด |
| การ์ดขึ้นซ้ำสองชุด | แก้แล้วในเวอร์ชันนี้ — ถ้ายังเจอ แปลว่ายังใช้โค้ดเก่า ให้วางโค้ดใหม่แล้ว Deploy เวอร์ชันใหม่ |
| ลิงก์แอดมินใช้ไม่ได้ (แก้ข้อมูลไม่ได้) | `key` ในลิงก์ไม่ตรง รัน `showBatteryLinks` เอาลิงก์ล่าสุดมาใช้ |
| **ปุ่มแอดมินหายไปหมด** | ลิงก์ที่เปิดไม่มี `?key=` — เกิดบ่อยเวลา Deploy เป็น *New deployment* เพราะ URL เปลี่ยนใหม่ แก้ได้ 2 ทาง: (1) กด **"🔑 เข้าโหมดแอดมิน"** ล่างสุดของหน้าแล้ววางกุญแจ หรือ (2) รัน `showBatteryLinks` เอาลิงก์แอดมินอันใหม่มาใช้ |
| Deploy แล้วลิงก์เดิมยังเป็นโค้ดเก่า | ครั้งต่อ ๆ ไปให้ใช้ **Manage deployments → ดินสอ → Version: New version** อย่ากด *New deployment* เพราะจะได้ URL ใหม่ทุกครั้ง |
