# Treasure Idle RPG — Asset Folder

วางไฟล์ภาพตามโครงสร้างนี้ (ดู asset manifest เต็มๆ ที่คอมเมนต์บนสุดของ `../treasure-idle-rpg.html`):

- `monsters/` — สไปรต์มอนสเตอร์ 15 ตัว (slime.png, bat.png, ... , demon_king.png)
- `equipment/` — ไอคอนอาวุธ/เกราะ/แหวน แยกตามระดับความหายาก
- `chests/` — ภาพกล่องสมบัติ (ปิด/เปิด) 5 ระดับความหายาก
- `ui/` — กรอบพาเนล, แถบเลือด, ปุ่ม, กรอบช่องไอเทม, ไอคอนเหรียญทอง
- `bg/` — ภาพพื้นหลังฉากต่อสู้ 10 แบบ ตามช่วงด่าน

รูปภาพทั้งหมดถูกตัดจาก sprite sheet ที่ให้มาและใส่ไว้ครบแล้ว (พื้นหลังโปร่งใสสำหรับไอคอนมอนสเตอร์/อุปกรณ์/กล่องสมบัติ)
หากต้องการเปลี่ยนรูปใดก็แทนที่ไฟล์เดิมได้เลย โดยชื่อไฟล์ต้องตรงกับที่โค้ดอ้างอิงไว้
(asset ส่วนที่ไม่ได้ผูกกับ gameplay เช่น axe.png, spear.png, bow.png, wand.png, boots.png,
gloves.png, helmet.png, potion_*.png ก็ถูกตัดเก็บไว้ในโฟลเดอร์ equipment/ ให้ด้วยเผื่อใช้ภายหลัง)
