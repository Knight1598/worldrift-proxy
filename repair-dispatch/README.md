# ฟอร์มส่งรถซ่อมข้ามสาขา (ฝั่งสาขาที่ส่งรถ)

ลิงก์แจกให้สาขาอื่นกรอกเวลาจะส่งรถมาซ่อมที่สาขาหลัก กรอกเสร็จรายการจะไปโผล่ที่
**แท็บ "🚚 รับรถเข้า"** ของระบบติดตามสถานะแบต/รถส่งซ่อมเดิมทันที ให้เจ้าหน้าที่ตรวจทะเบียนแล้วกดรับ

```
สาขาอื่น                          สาขาหลัก
─────────────────────────────    ────────────────────────────────
เปิดลิงก์ฟอร์มนี้                  แท็บ "รับรถเข้า" ในระบบเดิม
กรอกข้อมูล + แนบรูป      ─────►   การ์ดโผล่ (เก่าสุดอยู่บนสุด)
                                  ตรวจทะเบียนกับรถที่มาถึง
                                  กดรับรถ + ใส่ชื่อผู้รับ
                                        │
                                        ▼
                                  สถานะกลายเป็น "รอซ่อม"
                                  เข้าคิวซ่อมตามปกติ
```

**เป็นโปรเจกต์แยก มี URL ของตัวเอง แต่เขียนลง Google Sheet ไฟล์เดียวกันกับระบบเดิม**
สาขาที่ได้ลิงก์นี้ทำได้อย่างเดียวคือกรอกฟอร์ม — เห็นรายการของสาขาอื่นหรือแก้ข้อมูลไม่ได้เลย

| ฝั่ง | โฟลเดอร์ | ไฟล์ |
|---|---|---|
| สาขาที่ส่งรถ (ฟอร์ม) | `repair-dispatch/` **← โฟลเดอร์นี้** | `Code.gs`, `Form.html` |
| สาขาหลัก (หน้ารับรถ) | `battery-tracker/` | `Code.gs`, `Battery.html` |

> ต้องอัปเดต **ทั้งสองโปรเจกต์** เพราะฝั่งรับรถเป็นแท็บใหม่ในระบบเดิม
> ถ้าอัปเดตแต่ฝั่งฟอร์ม รายการจะเข้าชีตแต่ไม่มีหน้าให้กดรับ

---

## ขั้นตอนที่ 1 — อัปเดตระบบเดิมก่อน

ที่โปรเจกต์ Apps Script ของ **ระบบติดตามสถานะแบต/รถส่งซ่อม** (โฟลเดอร์ `battery-tracker`)

1. วาง `Code.gs` และ `Battery.html` เวอร์ชันใหม่ทับของเดิม → **Ctrl+S**
2. รัน **`setupSheets`** หนึ่งครั้ง (เติมคอลัมน์ใหม่ 6 ตัวให้ชีต `Repairs`)
3. **Deploy → Manage deployments → ดินสอ → Version: New version**
4. เปิดหน้าเว็บดู ต้องเห็นแท็บที่สาม **"🚚 รับรถเข้า"**

คอลัมน์ที่เพิ่มในชีต `Repairs` (ต่อท้ายด้านขวา ของเดิมไม่ขยับ):

| คอลัมน์ | เก็บอะไร |
|---|---|
| `BranchCode` | รหัสสาขาที่ส่ง (4 หลัก) |
| `PlateNo` | ข้อมูลขนส่ง + ทะเบียนรถ |
| `Source` | ที่มาของรายการ — จากฟอร์มนี้จะเป็น `สาขาอื่น` |
| `EvidenceImage` | ลิงก์รูปหลักฐานใน Drive |
| `ReceivedBy` | ชื่อคนที่กดรับรถ |
| `ReceivedAt` | เวลาที่กดรับรถ (ครบวินาที) |

และมีสถานะเพิ่มมาอีกหนึ่งขั้น: **`รอรับรถ (กำลังจัดส่ง)`** — คือรถที่กดส่งมาแล้วแต่ยังไม่ได้รับเข้า

---

## ขั้นตอนที่ 2 — สร้างโปรเจกต์ของฟอร์ม

โปรเจกต์นี้เป็น **สคริปต์เดี่ยว ไม่ผูกกับชีต** (จะได้ deploy แยก URL กับระบบเดิม)

1. ไปที่ <https://script.google.com> → **โครงการใหม่**
2. ตั้งชื่อโครงการ เช่น "ฟอร์มส่งรถซ่อมข้ามสาขา"
3. ก็อปวาง **2 ไฟล์**

   | ไฟล์ในโฟลเดอร์นี้ | ทำยังไงใน Apps Script |
   |---|---|
   | `Code.gs` | มีไฟล์ `Code.gs` อยู่แล้ว — เลือกทั้งหมด (Ctrl+A) → ลบ → วางเนื้อหาไฟล์นี้ทับ |
   | `Form.html` | กด **+** ข้าง Files → **HTML** → ตั้งชื่อ `Form` (ไม่ต้องพิมพ์ `.html`) แล้ววาง |

   > ชื่อไฟล์ HTML ต้องเป็น `Form` เป๊ะ ๆ เพราะโค้ดเรียกไฟล์นี้ตามชื่อ

4. กด **Ctrl+S**

---

## ขั้นตอนที่ 3 — บอกให้รู้ว่าจะเขียนลงชีตไฟล์ไหน (สำคัญ)

โปรเจกต์นี้ไม่ผูกกับชีต จึงต้องบอก id ของไฟล์ชีตที่ระบบเดิมใช้อยู่

1. เปิดไฟล์ Google Sheet ของระบบแบต/รถส่งซ่อม แล้วดู URL

   ```
   https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
                                          └────────── ส่วนนี้คือ id ──────────┘
   ```

2. ใน Apps Script ของโปรเจกต์นี้: **⚙ การตั้งค่าโครงการ** → เลื่อนลงล่างสุด
   **คุณสมบัติสคริปต์ → เพิ่มคุณสมบัติสคริปต์**

   | ชื่อ | ค่า |
   |---|---|
   | `SPREADSHEET_ID` | id ที่ก็อปมาจาก URL |

3. กด **บันทึกคุณสมบัติสคริปต์**

ถ้าลืมขั้นนี้ เปิดฟอร์มจะขึ้นข้อความบอกตรง ๆ ว่ายังไม่ได้ตั้ง `SPREADSHEET_ID`

---

## ขั้นตอนที่ 4 — ประกาศสิทธิ์ที่ต้องใช้ในไฟล์ manifest

ข้ามขั้นนี้แล้วมีสิทธิ์พลาดจะเจอ error ตอนแนบรูป (ดูหัวข้อ "แก้ปัญหา" ท้ายไฟล์)

1. **⚙ การตั้งค่าโครงการ** → ติ๊ก **"แสดงไฟล์ Manifest 'appsscript.json' ในตัวแก้ไข"**
2. กลับไปที่ตัวแก้ไข จะเห็นไฟล์ `appsscript.json` โผล่มาในรายการไฟล์
3. เปิดไฟล์นั้น แล้ววางเนื้อหาไฟล์ `appsscript.json` ในโฟลเดอร์นี้ทับทั้งไฟล์ → **Ctrl+S**

สิทธิ์ที่ประกาศไว้มี 2 อย่าง ใช้ทำอะไรบ้าง:

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| `spreadsheets` | อ่านรายชื่อสาขา และเขียนแถวลงชีต `Repairs` |
| `drive` | สร้างโฟลเดอร์และเก็บรูปหลักฐาน แล้วเปิดลิงก์ให้ดูรูปได้ |

> ที่ต้องเขียนไว้ตรง ๆ เพราะปกติ Apps Script เดารายการสิทธิ์จากโค้ดที่มีอยู่**ตอนกดอนุญาต**
> ถ้าเคยกดอนุญาตไว้ตอนวางโค้ดยังไม่ครบ โปรเจกต์จะค้างอยู่กับสิทธิ์ชุดเก่า
> แล้วพอถึงจังหวะเก็บรูปจริงถึงจะโดนปฏิเสธ ซึ่งไล่หาสาเหตุยาก

---

## ขั้นตอนที่ 5 — ขออนุญาตสิทธิ์ แล้วตรวจก่อน deploy

เลือกฟังก์ชัน **`authorize`** จากดรอปดาวน์ด้านบน แล้วกด **▶ เรียกใช้**

จะมีหน้าขอสิทธิ์เด้งขึ้นมา → **ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โครงการ (ไม่ปลอดภัย) → อนุญาต**
(ต้องใช้บัญชีเดียวกับที่ deploy ระบบเดิม ไม่งั้นจะเปิดชีตไม่ได้)

ดูผลที่ **"บันทึกการดำเนินการ"** ต้องได้ ✅ ทั้งสองข้อ:

```
✅ เปิดไฟล์ชีตได้: ...
✅ เข้าถึง Google Drive ได้
```

แล้วรัน **`checkSetup`** ต่อเพื่อดูภาพรวม ควรได้ครบทุกบรรทัด:

```
✅ ไฟล์ชีต: ...
✅ ชีต Branches (166 แถว)
✅ ชีต Repairs (... แถว)
✅ คอลัมน์ที่ต้องใช้ครบแล้ว
✅ สาขาที่เลือกได้: 166 สาขา
📁 โฟลเดอร์รูปหลักฐาน: หลักฐานรถส่งซ่อมข้ามสาขา
```

ถ้าขึ้น `⚠️ ยังไม่มีคอลัมน์ ...` ก็ยังใช้ได้ — ระบบจะเติมคอลัมน์ให้เองตอนมีคนส่งครั้งแรก
(หรือกลับไปรัน `setupSheets()` ที่โปรเจกต์เดิมก็ได้)

ถ้าขึ้น `❌ Google Drive: ...` **อย่าข้ามไป deploy** ให้แก้ตามหัวข้อ "แก้ปัญหา" ท้ายไฟล์ก่อน
ไม่งั้นสาขากรอกฟอร์มแล้วจะส่งไม่ได้ทุกคน

---

## ขั้นตอนที่ 6 — Deploy แล้วเอาลิงก์ไปแจก

1. **Deploy → New deployment** → ชนิด **Web app**
2. **Execute as**: `Me` / **Who has access**: `Anyone`
3. กด **Deploy** แล้วก็อปลิงก์ `.../exec`

รันฟังก์ชัน **`showFormUrl`** ก็ดูลิงก์ได้เหมือนกัน

**ลิงก์นี้แจกให้สาขาอื่นได้เลย** ไม่ต้องมีรหัสอะไร กรอกได้อย่างเดียว
(ต่างจากลิงก์แอดมินของระบบเดิมที่ **ห้ามส่งให้สาขา**)

> ครั้งต่อ ๆ ไปที่แก้โค้ด ให้ใช้ **Manage deployments → ดินสอ → Version: New version**
> อย่ากด *New deployment* เพราะจะได้ URL ใหม่ทุกครั้ง สาขาที่บันทึกลิงก์เก่าไว้จะใช้ของเดิมต่อ

## ช่องที่สาขาต้องกรอก (บังคับทุกช่อง)

| ช่อง | หมายเหตุ |
|---|---|
| สาขาที่ส่ง | ช่องพิมพ์ค้นหา **พิมพ์รหัสสาขาเช่น `0132` หรือชื่อสาขาก็ได้** |
| โซน | ระบบเติมให้เองจากสาขาที่เลือก |
| เลขที่ใบจ๊อบ | ห้ามซ้ำกับคันที่ยังรอรับอยู่ (ดูหัวข้อถัดไป) |
| รุ่นรถ | |
| ข้อมูลขนส่ง + ทะเบียนรถ | ตัวนี้คือตัวที่เจ้าหน้าที่ใช้ตรวจตอนรถมาถึง ใส่ให้ครบ |
| ชื่อผู้ส่ง | |
| อาการเบื้องต้น | ช่องหลายบรรทัด เล่าอาการที่เจอ |
| รูปหลักฐาน | ถ่ายรถหรือใบจ๊อบก็ได้ |

**สาขาที่ยังไม่เข้าระบบ** เลือก **"อื่น ๆ (ระบุเอง)"** ในช่องสาขา แล้วพิมพ์ชื่อสาขาและโซนเอง

**ส่งหลายคันติดกัน** กดปุ่ม **"ส่งรถคันต่อไป"** บนการ์ดสรุป — สาขาและโซนเดิมยังอยู่
เหลือแค่กรอกข้อมูลคันใหม่

## กันส่งซ้ำ

**เลขที่ใบจ๊อบเดิมส่งซ้ำไม่ได้ ถ้าคันก่อนยังสถานะ `รอรับรถ (กำลังจัดส่ง)`**
ระบบจะบอกว่าไปชนกับเลขที่รายการไหน จากสาขาไหน

พอสาขาหลักกดรับรถแล้ว (สถานะกลายเป็น `รอซ่อม`) **ใบจ๊อบเดิมส่งได้อีก** —
เผื่อรถคันนั้นต้องส่งซ่อมรอบสอง

## รูปหลักฐาน

- รูปถูก**ย่อในเครื่องก่อนส่ง** (ด้านยาว 1600px) และหมุนตาม EXIF ให้ถูกด้าน
  มือถือถ่ายมา 4-8MB ส่งตรง ๆ จะหลุดโควตา
- เก็บในโฟลเดอร์ **"หลักฐานรถส่งซ่อมข้ามสาขา"** ใน Google Drive ของบัญชีที่ deploy
- ตั้งชื่อไฟล์เป็น **`เลขที่ใบจ๊อบ_วันที่.นามสกุล`** เช่น `JOB-2568-0123_2026-08-12.jpg`
- **ไฟล์ถูกเปิดสิทธิ์ให้ "ใครก็ดูได้ถ้ามีลิงก์"** เพื่อให้เจ้าหน้าที่ที่หน้ารับรถกดดูได้ทันที
  ตัวลิงก์เดาไม่ได้ แต่ **ใครที่ได้ลิงก์ไปก็เปิดดูได้** — อย่าถ่ายเอกสารที่มีข้อมูลส่วนตัวลูกค้า
  ถ้าองค์กรตั้งนโยบายห้ามแชร์ลิงก์สาธารณะ ระบบจะข้ามขั้นนี้ให้เอง (รูปยังเก็บครบ
  แต่คนที่จะเปิดดูต้องมีสิทธิ์ใน Drive อยู่แล้ว)
- ตั้งโฟลเดอร์เองได้ด้วยการเพิ่ม Script Property `EVIDENCE_FOLDER_ID`

**ไฟล์ .HEIC ของไอโฟน** เบราว์เซอร์เปิดตรง ๆ ไม่ได้ — ฟอร์มจะบอกทางแก้ให้
วิธีที่เร็วที่สุดคือกดปุ่มในฟอร์มแล้วถ่ายใหม่ (รูปที่ถ่ายผ่านฟอร์มเป็น JPG)
หรือตั้งค่ากล้อง → รูปแบบ → **"เข้ากันได้มากที่สุด"**

## ฝั่งสาขาหลัก — หน้ารับรถ

แท็บ **"🚚 รับรถเข้า"** ในระบบเดิม

- การ์ดเรียง **คันที่ส่งมาก่อนอยู่บนสุด** จะได้ไม่มีคันตกค้าง
- **ทะเบียนอยู่บนสุดตัวใหญ่** เพราะเป็นตัวที่ใช้ตรวจกับรถที่มาถึงจริง
- หน้านี้**รีเฟรชเองทุก 60 วินาที** และมีปุ่มรีเฟรชให้กดเอง
- **สาขาทั่วไปเปิดดูได้ แต่ไม่มีปุ่มรับรถ** — ต้องอยู่ในโหมดแอดมิน (กดปุ่มกุญแจ 🔑)
- กด **"✅ รับรถคันนี้"** → แผงยืนยันกางในการ์ด **โชว์ทะเบียนกับรุ่นรถให้ตรวจอีกครั้ง**
  → ใส่ชื่อผู้รับรถ → **"ยืนยันรับรถ"**
- รับแล้ว: สถานะกลายเป็น **"รอซ่อม"**, บันทึกชื่อผู้รับและเวลา, **การ์ดหายไปจากหน้านี้**
  แล้วไปโผล่ในแท็บ "🔧 รถส่งซ่อม" ตามปกติ
- ถ้ามีคนอื่นกดรับคันเดียวกันไปก่อน คนที่มาทีหลังจะขึ้นว่ารายการนี้ถูกรับไปแล้ว
  (ตรวจที่ฝั่งเซิร์ฟเวอร์ตอนถือล็อกอยู่ ไม่ใช่แค่ซ่อนปุ่ม)

## ฟังก์ชันที่รันเองได้จาก Apps Script

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `authorize()` | ขออนุญาตสิทธิ์ให้ครบ (ชีต + Drive) แล้วบอกว่าผ่านหรือติดอะไร — รันตัวนี้ก่อนตัวอื่นเสมอ |
| `checkSetup()` | ตรวจว่าต่อกับชีตถูกไฟล์ คอลัมน์ครบไหม สาขากี่แห่ง และลิงก์ฟอร์มคืออะไร |
| `showFormUrl()` | ดูลิงก์ฟอร์มสำหรับแจกสาขา |

---

## ระบบนี้ไม่ทำอะไรกับชีตเดิม

ตั้งใจกันไว้ตั้งแต่ออกแบบ เพราะเขียนลงไฟล์เดียวกับระบบที่ใช้งานอยู่จริง

- **ไม่สร้างชีตใหม่** ใช้ `Repairs` กับ `Branches` ที่มีอยู่
- **ไม่ลบและไม่สลับลำดับคอลัมน์เดิม** คอลัมน์ที่ยังไม่มีจะถูก**ต่อท้ายด้านขวา**เท่านั้น
- **อ่าน/เขียนโดยอ้างชื่อหัวตาราง** ไม่ได้อ้างเลขคอลัมน์ ใครไปแทรกคอลัมน์ในชีตก็ไม่พัง
- **จัดรูปแบบ "ข้อความ" แค่แถวที่เพิ่งเขียน** ไม่ลากทับทั้งคอลัมน์ แถวเก่าจึงไม่เสียรูปแบบ
  (ที่ต้องล็อกเพราะ Sheets ชอบแปลง `2026-08-12 09:30:00` เป็นวันที่ และตัด 0 นำหน้าของรหัสสาขาทิ้ง)
- **ทุกการเขียนอยู่ใต้ `LockService`** และปล่อยล็อกใน `finally` เสมอ สองสาขากดส่งพร้อมกันก็ไม่ทับกัน
- **ไม่แตะชีต `Batteries`** เลย

## ถ้าขึ้นว่าไม่ได้รับอนุญาตให้ใช้ Google Drive

ข้อความจะประมาณนี้ (เจอได้ทั้งตอนรัน `checkSetup` และตอนสาขากดส่งฟอร์ม):

```
คุณไม่ได้รับอนุญาตให้เรียกใช้ DriveApp.getFoldersByName
สิทธิ์ที่จำเป็นคือ (https://www.googleapis.com/auth/drive.readonly ||
https://www.googleapis.com/auth/drive)
```

**สาเหตุ**: ตอนกดอนุญาตครั้งแรก Apps Script ขอสิทธิ์ไปแค่บางส่วน (ได้สิทธิ์ชีต แต่ไม่ได้สิทธิ์ Drive)
เพราะมันคิดรายการสิทธิ์จากโค้ดที่มีอยู่ ณ ตอนนั้น พอกดอนุญาตไปแล้ว
มันจะไม่ถามใหม่เองแม้โค้ดจะต้องใช้สิทธิ์เพิ่ม — และเว็บแอปที่ deploy ไปแล้วก็ใช้สิทธิ์ชุดเก่านั้นต่อ

**วิธีแก้ ทำตามลำดับ**

1. วาง `appsscript.json` ให้เรียบร้อยตาม **ขั้นตอนที่ 4** (ประกาศสิทธิ์ทั้งสองไว้ตรง ๆ) → **Ctrl+S**
2. รันฟังก์ชัน **`authorize`** → หน้าขอสิทธิ์จะเด้งขึ้นมาใหม่ กดอนุญาตให้ครบทุกข้อ
   **สังเกตให้แน่ใจว่ามีข้อที่เขียนถึง Google ไดรฟ์อยู่ในรายการด้วย**
3. **Deploy → Manage deployments → ดินสอ → Version: New version** (ข้อนี้ลืมไม่ได้ —
   ถ้าไม่ทำ เว็บแอปจะยังรันด้วยสิทธิ์ชุดเก่าทั้งที่ในตัวแก้ไขผ่านแล้ว)
4. เปิดลิงก์ฟอร์ม ลองส่งทดสอบหนึ่งรายการ

**ถ้ารัน `authorize` แล้วไม่มีหน้าขอสิทธิ์เด้งขึ้นมาเลย** (ยังขึ้น error เดิม) แปลว่า Google
ยังยึดสิทธิ์ชุดเก่าไว้ ต้องถอนออกก่อน:

1. ไปที่ <https://myaccount.google.com/connections> (หรือ บัญชี Google → ความเป็นส่วนตัว →
   **แอปของบุคคลที่สามที่มีสิทธิ์เข้าถึงบัญชี**)
2. หาชื่อโปรเจกต์นี้ → **ลบการเข้าถึง**
3. กลับไปที่ Apps Script รัน `authorize` อีกครั้ง → หน้าขอสิทธิ์จะเด้งใหม่ครบทุกข้อ
4. Deploy เวอร์ชันใหม่ตามข้อ 3 ข้างบน

> **ถ้าองค์กรบล็อกสิทธิ์ Drive ไว้** (ผู้ดูแลระบบ Workspace ตั้งค่าห้าม) จะกดอนุญาตไม่ผ่านเลย
> กรณีนั้นต้องให้ผู้ดูแลอนุญาตแอปนี้ให้ก่อน — ไม่มีทางแก้จากในโค้ด เพราะฟอร์มต้องเก็บรูปลง Drive

> **ถ้าขึ้นชื่อสิทธิ์อื่นที่ไม่ใช่ Drive** (เช่นบางเวอร์ชันของ Google ขอ `script.external_request`)
> ให้ก็อปลิงก์สิทธิ์จากข้อความ error ไปเพิ่มในลิสต์ `oauthScopes` ของ `appsscript.json`
> แล้วทำข้อ 2-3 ซ้ำ
