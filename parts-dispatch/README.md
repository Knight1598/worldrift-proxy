# ระบบบันทึกการส่งอะไหล่ + แจ้งเตือนกลุ่มไลน์

ระบบเล็ก ๆ สำหรับธุรการคลังอะไหล่ ใช้ Google Sheets เป็นฐานข้อมูล + Google Apps Script
เป็นตัวกลาง ไม่ต้องเช่าเซิร์ฟเวอร์ ไม่มีค่าใช้จ่ายฝั่ง Google

**แก้ปัญหาอะไร**

| ปัญหาเดิม | ระบบช่วยยังไง |
|---|---|
| จำไม่ได้ว่าสาขาไหนอยู่เขตขนส่งไหน | เลือกสาขา → เขตขนส่งกับขนส่งประจำเด้งขึ้นมาเอง จากตาราง `Branches` |
| จำไม่ได้ว่าส่งไปกับขนส่งเจ้าไหน | บันทึกขนส่ง + เลขพัสดุทุกรอบ ค้นย้อนหลังได้ |
| จำไม่ได้ว่าชิ้นไหนฝากลงสาขาอื่น | แยกช่อง "สาขาปลายทาง" กับ "จุดฝากลง" ชัดเจน และไฮไลต์ ⚠️ ในข้อความไลน์ |

---

## สิ่งที่ต้องเตรียม

- บัญชี Google (ใช้สร้าง Sheet + Apps Script)
- บัญชี LINE สำหรับสร้าง **LINE Official Account** — ฟรี
- กลุ่มไลน์ที่ต้องการให้ระบบแจ้งเตือน

> **หมายเหตุสำคัญ:** LINE Notify ปิดบริการไปแล้วเมื่อ 31 มี.ค. 2568
> การยิงข้อความเข้ากลุ่มอัตโนมัติตอนนี้ต้องใช้ LINE Official Account + Messaging API
> โดยเชิญบอทเข้ากลุ่ม แล้วส่งข้อความไปที่ `groupId` ของกลุ่มนั้น

---

## ขั้นตอนที่ 1 — สร้างชีตและวางโค้ด

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "คลังอะไหล่ - บันทึกส่งของ"
2. เมนู **Extensions → Apps Script**
3. ก็อปวางแค่ **2 ไฟล์** ตามนี้

   | ไฟล์ในโฟลเดอร์นี้ | ทำยังไงใน Apps Script |
   |---|---|
   | `Code.gs` | มีไฟล์ `Code.gs` อยู่แล้วตั้งแต่แรก — **ลบโค้ดเดิมทิ้งทั้งหมด** แล้ววางเนื้อหาไฟล์นี้ทับ |
   | `App.html` | กด **+** ข้าง Files → **HTML** → ตั้งชื่อ `App` (ไม่ต้องพิมพ์ `.html`) แล้ววางเนื้อหาไฟล์นี้ |

   > ชื่อไฟล์ HTML ต้องเป็น `App` เป๊ะ ๆ เพราะโค้ดฝั่งเซิร์ฟเวอร์เรียกไฟล์นี้ตามชื่อ

4. กด **Save**

> ถ้าถนัดใช้ `clasp` ก็ `clasp clone <scriptId>` แล้ว `clasp push` จากโฟลเดอร์นี้ได้เลย
> (`appsscript.json` เตรียมไว้ให้แล้ว)

---

## ขั้นตอนที่ 2 — สร้างโครงสร้างชีตและใส่ข้อมูลสาขา

1. ใน Apps Script เลือกฟังก์ชัน `setupSheets` แล้วกด **Run**
   (ครั้งแรกจะขอสิทธิ์เข้าถึงชีต → Review permissions → Advanced → Go to … → Allow)
2. กลับไปที่ชีต จะได้แท็บใหม่ 6 แท็บ พร้อมข้อมูลตัวอย่าง
3. **แก้แท็บ `Branches` ให้เป็นสาขาจริงของบริษัท** — นี่คือหัวใจของระบบ

   | คอลัมน์ | ความหมาย |
   |---|---|
   | `branchCode` | รหัสสาขา (ใส่หรือเว้นก็ได้) |
   | `branchName` | ชื่อสาขา — ตัวนี้จะไปโผล่ใน dropdown |
   | `zone` | เขตขนส่ง เช่น อีสานเหนือ / ภาคกลาง |
   | `defaultCarrier` | ขนส่งที่ใช้ประจำ ระบบจะเลือกให้อัตโนมัติ |
   | `defaultDropPoint` | จุดลงของปกติ (ปกติใส่ชื่อสาขาตัวเอง) |
   | `active` | ใส่ `FALSE` เมื่อเลิกใช้สาขานั้น จะหายจาก dropdown |

4. แก้แท็บ `Carriers` ให้เป็นเจ้าขนส่งที่ใช้จริง
5. แท็บ `DropPoints` ใส่จุดฝากลงที่ **ไม่ใช่สาขา** เช่น ท่ารถ ปั๊ม ร้านค้า (ถ้ามี)
6. แท็บ `Parts` ไม่ต้องกรอกก็ได้ — ระบบจะจำอะไหล่ที่คีย์ไปแล้วเข้ามาเองเรื่อย ๆ
   เพื่อทำ autocomplete ในรอบถัด ๆ ไป

---

## ขั้นตอนที่ 3 — สร้าง LINE Official Account และเอา Token

1. เข้า <https://developers.line.biz/console/> → ล็อกอินด้วยบัญชี LINE
2. สร้าง **Provider** (ชื่ออะไรก็ได้ เช่น ชื่อบริษัท)
3. สร้าง **Channel** ชนิด **Messaging API** — ชื่อ Channel คือชื่อบอทที่จะเห็นในกลุ่ม
   เช่น "แจ้งส่งอะไหล่"
4. แท็บ **Messaging API** → เลื่อนลงล่างสุด → **Channel access token (long-lived)** → **Issue**
   → ก็อปเก็บไว้
5. ในหน้าเดียวกัน เปิด **Allow bot to join group chats** ให้เป็น **Enabled**
   (อยู่ในลิงก์ไปหน้า LINE Official Account Manager → Settings → Chat)
6. แนะนำให้ปิด **Auto-reply messages** และ **Greeting messages** เพื่อไม่ให้บอทตอบรก ๆ ในกลุ่ม

### ใส่ Token เข้าระบบ

Apps Script → ไอคอนเฟือง **Project Settings** → **Script Properties** → **Add script property**

| Property | Value |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | token ยาว ๆ ที่ก็อปมาจากข้อ 4 |
| `APP_PIN` | ตัวเลข 4-6 หลักที่ทีมใช้ร่วมกัน (แนะนำให้ตั้ง — ดูเหตุผลท้ายเอกสาร) |

> Token เก็บอยู่ใน Script Properties เท่านั้น **ห้ามเขียนลงในโค้ดหรือ commit ขึ้น git**

## ขั้นตอนที่ 4 — Deploy เว็บแอป

1. Apps Script → **Deploy → New deployment** → เลือกชนิด **Web app**
2. ตั้งค่า
   - **Execute as**: `Me`
   - **Who has access**: `Anyone` ← ต้องเป็นค่านี้ตอนตั้งค่า LINE webhook
3. กด **Deploy** แล้วก็อป **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

URL นี้คือลิงก์ที่เอาไปเปิดบนมือถือเพื่อคีย์งาน — แนะนำให้กด "เพิ่มลงในหน้าจอโฮม"
(Add to Home Screen) จะได้เปิดเหมือนแอป

---

## ขั้นตอนที่ 5 — จับคู่กลุ่มไลน์

1. กลับไปที่ LINE Developers Console → แท็บ **Messaging API** → **Webhook URL**
   ใส่ **Web app URL** จากขั้นตอนที่ 4 → **Update** → เปิด **Use webhook**
   > ปุ่ม **Verify** อาจขึ้น error เพราะ Apps Script ตอบด้วยการ redirect — **ไม่ต้องสนใจ**
   > ของจริงใช้งานได้
2. ใน Apps Script รันฟังก์ชัน **`pairingModeOn`**
3. เชิญบอท (LINE OA ที่เพิ่งสร้าง) เข้ากลุ่มไลน์ที่ต้องการ
   — สแกน QR จากแท็บ Messaging API ของ Console หรือค้นจาก Basic ID
4. **พิมพ์ข้อความอะไรก็ได้ในกลุ่ม** เช่น "test"
5. บอทจะตอบกลับว่า "✅ จับคู่กลุ่มสำเร็จ" — ระบบเก็บ `groupId` ให้อัตโนมัติ
   และปิดโหมดจับคู่ให้เองทันที
6. รันฟังก์ชัน `checkSetup` เพื่อยืนยันว่ามี `LINE_GROUP_ID` แล้ว

> **หลังจับคู่เสร็จแล้ว** จะไม่ต้องใช้ webhook อีก ถ้าอยากปลอดภัยขึ้นสามารถ
> ปิด **Use webhook** ใน Console และเปลี่ยน deployment เป็น
> **Who has access: Anyone with Google account** ได้ (แต่ทุกคนที่คีย์งานต้องล็อกอิน Google)

---

## ขั้นตอนที่ 6 — ทดสอบ

1. รันฟังก์ชัน `testLineMessage` → ต้องเห็นข้อความทดสอบเด้งในกลุ่ม
2. เปิด Web app URL บนมือถือ → ใส่ PIN (ถ้าตั้งไว้)
3. ลองบันทึก 1 รอบแบบส่งตรง → เช็คว่าแถวขึ้นในแท็บ `Shipments` และ `Items` และมีข้อความในกลุ่ม
4. ลองบันทึกแบบฝากลง (ปลายทางขอนแก่น ติ๊ก "ฝากลงที่อื่น" เลือกกันทรวิชัย)
   → ในไลน์ต้องมีบรรทัด `⚠️ ฝากลงที่: กันทรวิชัย` และคอลัมน์ `isTransfer` เป็น `TRUE`
5. กดแท็บ "ประวัติ" ด้านบน → ค้นด้วยรหัสอะไหล่ที่เพิ่งคีย์ → ต้องเจอ

## การใช้งานประจำวัน

- **คีย์งาน**: เปิดลิงก์เว็บแอป → เลือกวันที่/สาขา → ระบบเติมเขตกับขนส่งให้ →
  ใส่รายการอะไหล่ → กดบันทึก
- **ฝากลงที่อื่น**: ติ๊กสวิตช์ "ฝากลงที่อื่น" แล้วเลือกจุดฝากลง (เลือกสาขาอื่นหรือจุดใน `DropPoints` ได้
  ถ้าไม่มีในลิสต์ เลือก "อื่น ๆ (พิมพ์เอง)")
- **ค้นย้อนหลัง**: แท็บ "ประวัติ" ด้านบน — ค้นด้วยรหัสอะไหล่ ชื่ออะไหล่ เลขพัสดุ เลขที่บิล หรือชื่อสาขา
  และกรองเฉพาะรายการที่ฝากลงที่อื่นได้
- **แก้ข้อมูลย้อนหลัง**: แก้ในชีตได้ตรง ๆ (ระบบไม่ล็อกอะไร) แต่ข้อความที่ส่งไลน์ไปแล้วจะไม่เปลี่ยนตาม

---

## เรื่องที่ควรรู้

**ถ้าส่งไลน์ไม่สำเร็จ** ข้อมูลจะถูกบันทึกลงชีตเรียบร้อยแล้วเสมอ (เขียนชีตก่อน ค่อยยิงไลน์)
คอลัมน์ `lineStatus` จะขึ้น `FAILED: ...` และกด "ส่งเข้ากลุ่มไลน์ซ้ำ" ได้จากหน้าประวัติ

**กันบันทึกซ้ำ** ทุกครั้งที่เปิดฟอร์มจะมี token ประจำรอบ ถ้าเน็ตหลุดแล้วกดซ้ำ
ระบบจะรู้ว่าเป็นรายการเดิม ไม่เขียนแถวใหม่และไม่ยิงไลน์ซ้ำ

**ทำไมควรตั้ง `APP_PIN`** เพราะ deployment ตั้งเป็น "Anyone" (จำเป็นสำหรับ LINE webhook)
แปลว่าใครได้ลิงก์ไปก็เปิดฟอร์มได้ PIN เป็นด่านกันคนนอกคีย์มั่ว
ถ้าไม่ตั้ง ระบบจะข้ามด่านนี้ไปเลย

**โควตาข้อความ LINE** แพ็กเกจฟรีของ LINE OA มีจำนวนข้อความจำกัดต่อเดือน
ตัวเลขเปลี่ยนตามประกาศของ LINE ให้เช็คหน้าราคาตอนสมัคร ถ้าส่งวันละหลายรอบจนไม่พอ
ทางแก้คือเปลี่ยนไปส่ง "สรุปรวมท้ายวันครั้งเดียว" แทน (เพิ่ม time-based trigger ได้ในภายหลัง)

**ข้อจำกัดด้านความปลอดภัยของ webhook** Apps Script อ่าน HTTP header ไม่ได้
จึงตรวจลายเซ็น `X-Line-Signature` ไม่ได้ ระบบจึงยอมรับ webhook เฉพาะตอนเปิด `PAIRING_MODE`
และปิดโหมดทันทีที่จับคู่สำเร็จ นอกช่วงนั้น event ทุกอันจะถูกทิ้ง

## Script Properties ทั้งหมด

| Key | จำเป็น | ความหมาย |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | ใช่ | Channel access token จาก LINE Developers |
| `LINE_GROUP_ID` | ใช่ | ระบบเติมให้เองตอนจับคู่กลุ่ม |
| `APP_PIN` | แนะนำ | PIN เข้าใช้ฟอร์ม ถ้าเว้นว่าง = ไม่ถาม PIN |
| `PAIRING_MODE` | อัตโนมัติ | `true` เฉพาะช่วงจับคู่กลุ่ม |
| `SPREADSHEET_ID` | ไม่ | ใส่เมื่อสคริปต์ไม่ได้ผูกกับไฟล์ชีตโดยตรง |

## ฟังก์ชันที่รันเองได้จาก Apps Script

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupSheets()` | สร้าง/ซ่อมโครงสร้างชีต (รันซ้ำได้ ไม่ลบข้อมูล) |
| `checkSetup()` | ตรวจว่าตั้งค่าครบหรือยัง |
| `testLineMessage()` | ทดสอบส่งข้อความเข้ากลุ่ม |
| `pairingModeOn()` / `pairingModeOff()` | เปิด/ปิดโหมดจับคู่กลุ่ม |
| `showWebAppUrl()` | ดู URL ของเว็บแอป |

เมื่อสคริปต์ผูกกับชีต จะมีเมนู **"ระบบส่งอะไหล่"** บนแถบเมนูของชีต เรียกฟังก์ชันพวกนี้ได้เลย
(ถ้าเมนูไม่ขึ้น ให้รีเฟรชหน้าชีตหนึ่งครั้ง)

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น "ไม่พบชีต ..." | ยังไม่ได้รัน `setupSheets()` |
| บอทไม่ตอบตอนจับคู่ | ยังไม่ได้เปิด `pairingModeOn()` / ยังไม่ได้เปิด Use webhook / บอทยังไม่ได้เข้ากลุ่ม |
| ส่งไลน์ไม่ผ่าน ขึ้น HTTP 401 | Token ผิดหรือหมดอายุ ออก token ใหม่แล้วอัปเดต Script Properties |
| ส่งไลน์ไม่ผ่าน ขึ้น HTTP 400 | `groupId` ไม่ถูกต้อง หรือบอทถูกเตะออกจากกลุ่มแล้ว ให้จับคู่ใหม่ |
| แก้โค้ดแล้วเว็บยังเป็นของเดิม | ต้อง **Deploy → Manage deployments → แก้ไข → Version: New version** ทุกครั้ง |
| เพิ่มสาขาในชีตแล้ว dropdown ยังไม่ขึ้น | ระบบแคชข้อมูลหลักไว้ 5 นาที รอสักครู่แล้วรีเฟรช หรือรัน `setupSheets()` เพื่อล้างแคช |

## สิ่งที่ยังไม่มีในเวอร์ชันนี้

ตามที่ตกลงไว้ เฟสแรกเอาแค่ "บันทึก + แจ้งไลน์" ยังไม่มี:

- การยืนยันรับของจากปลายทาง (ปุ่มกดในไลน์ว่า "รับของแล้ว")
- สรุปรายวัน/รายสัปดาห์อัตโนมัติ
- การตัดสต็อกคลัง

โครงสร้างชีตออกแบบเผื่อไว้แล้ว เพิ่มคอลัมน์สถานะทีหลังได้โดยไม่ต้องรื้อของเดิม
