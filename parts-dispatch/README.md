# ระบบบันทึกการส่งอะไหล่ (เลขที่ใบ PR / เขต / สาขา / ขนส่ง)

ระบบเล็ก ๆ สำหรับธุรการคลังอะไหล่ ใช้ Google Sheets เป็นฐานข้อมูล + Google Apps Script
เป็นตัวกลาง ไม่ต้องเช่าเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย ไม่ต้องสมัครบริการเสริมใด ๆ

กรอกเลขที่ใบ PR → เลือกเขต → เลือกสาขาในเขตนั้น → เลือกขนส่ง → ใส่รายการอะไหล่ → กดบันทึก
แล้วดู/กรองรายงานย้อนหลังได้จากแท็บ "รายงาน" ในหน้าเดียวกัน

**แก้ปัญหาอะไร**

| ปัญหาเดิม | ระบบช่วยยังไง |
|---|---|
| จำไม่ได้ว่าสาขาไหนอยู่เขตไหน | เลือกเขตก่อน แล้วสาขาที่โผล่มาจะกรองเหลือเฉพาะสาขาในเขตนั้น (ใช้ข้อมูลจริง 53 เขต 166 สาขา) |
| จำไม่ได้ว่าส่งไปกับขนส่งเจ้าไหน | บันทึกขนส่ง + เลขพัสดุทุกรอบ ค้นย้อนหลังได้ |
| จำไม่ได้ว่าชิ้นไหนฝากลงสาขาอื่น | แยกช่อง "สาขาปลายทาง" กับ "จุดฝากลง" ชัดเจน มีสวิตช์ "ฝากลงที่อื่น" และไฮไลต์ในรายงาน |

---

## ขั้นตอนที่ 1 — สร้างชีตและวางโค้ด

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น "คลังอะไหล่ - บันทึกส่งของ"
2. เมนู **Extensions → Apps Script**
3. ก็อปวางแค่ **2 ไฟล์** ตามนี้

   | ไฟล์ในโฟลเดอร์นี้ | ทำยังไงใน Apps Script |
   |---|---|
   | `Code.gs` | มีไฟล์ `Code.gs` อยู่แล้วตั้งแต่แรก — เลือกทั้งหมด (Ctrl+A) → ลบ → วางเนื้อหาไฟล์นี้ทับ |
   | `App.html` | กด **+** ข้าง Files → **HTML** → ตั้งชื่อ `App` (ไม่ต้องพิมพ์ `.html`) แล้ววางเนื้อหาไฟล์นี้ |

   > ชื่อไฟล์ HTML ต้องเป็น `App` เป๊ะ ๆ เพราะโค้ดฝั่งเซิร์ฟเวอร์เรียกไฟล์นี้ตามชื่อ

4. กด **Ctrl+S** บันทึก

> ถ้าถนัดใช้ `clasp` ก็ `clasp clone <scriptId>` แล้ว `clasp push` จากโฟลเดอร์นี้ได้เลย
> (`appsscript.json` เตรียมไว้ให้แล้ว)

## ขั้นตอนที่ 2 — สร้างโครงสร้างชีต (มีข้อมูลสาขาจริงมาให้แล้ว)

1. ในแถบด้านบนของ Apps Script เปลี่ยนจาก `myFunction` เป็น **`setupSheets`** แล้วกด **▶ เรียกใช้**
   (ครั้งแรกจะขอสิทธิ์เข้าถึงชีต → ตรวจสอบสิทธิ์ → เลือกบัญชี → ขั้นสูง → ไปที่โครงการไม่มีชื่อ (ไม่ปลอดภัย) → อนุญาต)
2. กลับไปที่ชีต จะได้แท็บใหม่ 6 แท็บ โดยแท็บ **`Branches`** จะมีสาขาจริงเติมมาให้ครบ
   **166 สาขา ใน 53 เขต** อยู่แล้ว (ดึงจากตารางจัดเขตขายที่ให้มา) ไม่ต้องพิมพ์เอง

   | คอลัมน์ | ความหมาย |
   |---|---|
   | `branchCode` | รหัสสาขา 4 หลัก |
   | `branchName` | ชื่อสาขา — ตัวนี้จะไปโผล่ใน dropdown |
   | `zone` | เขต รูปแบบ `รหัสเขต:ชื่อผู้ดูแล` เช่น `40:โฟร์` |
   | `defaultCarrier` | ขนส่งที่ใช้ประจำของสาขานั้น (ยังว่างอยู่ กรอกเองได้ถ้าต้องการให้ระบบเดาขนส่งให้อัตโนมัติ) |
   | `defaultDropPoint` | จุดลงของปกติ ปล่อยว่างได้ ระบบจะถือว่าคือสาขาตัวเอง |
   | `active` | ใส่ `FALSE` เมื่อเลิกใช้สาขานั้น จะหายจาก dropdown |

   ถ้าสาขาจริงมีเปลี่ยนแปลง (เพิ่ม/ปิด/ย้ายเขต) แก้ในตารางนี้ได้ตรง ๆ เลย
3. แก้แท็บ **`Carriers`** ให้เป็นเจ้าขนส่งที่ใช้จริง (มีตัวอย่างเติมไว้ให้ 5 แถว แก้ทับได้เลย)
4. แท็บ **`DropPoints`** ใส่จุดฝากลงที่ **ไม่ใช่สาขา** เช่น ท่ารถ ปั๊ม ร้านค้า (ถ้ามี ไม่บังคับ)
5. แท็บ **`Parts`** คือตารางแม่ของรายการสินค้า — ใส่ข้อมูลตรงนี้แล้วเวลาคีย์งานจะพิมพ์แค่รหัส
   ชื่อสินค้าจะเด้งเข้ามาให้เอง

   | คอลัมน์ | ความหมาย |
   |---|---|
   | `partCode` | รหัสสินค้า |
   | `partName` | ชื่อสินค้า |
   | `status` | `ใช้งาน` หรือ `เลิกใช้` (เว้นว่าง = ใช้งาน) |
   | `replacedBy` | รหัสที่ใช้แทน เมื่อของตัวนี้เลิกใช้แล้ว |
   | `note` | หมายเหตุ |
   | `updatedAt` | ระบบใส่ให้เองตอนเพิ่ม/แก้ไข |

   ตอนนำเข้าครั้งแรกกรอกแค่ 2 คอลัมน์แรกก็พอ ที่เหลือมาแก้ทีหลังผ่านแท็บ "อะไหล่" ในเว็บได้

   **วิธีนำรายการสินค้าเข้า** (ทำครั้งเดียว แล้วอัปเดตเป็นรอบ ๆ เมื่อมีของใหม่):
   1. เปิดหน้ารายการสินค้าในระบบของบริษัท (ล็อกอินตามปกติ) ให้แสดงรายการทั้งหมด
   2. ลากคลุมทั้งตาราง → **Ctrl+C**
   3. มาที่ชีต `Parts` → คลิกช่อง **A2** → **Ctrl+V**
      (ตาราง HTML จะวางลง Google Sheets แยกเป็นช่อง ๆ ให้เอง)
   4. ลบคอลัมน์ที่ไม่ต้องการทิ้ง ให้เหลือแค่ **รหัสสินค้า** กับ **ชื่อสินค้า** ตามลำดับ

   ถ้าระบบมีปุ่ม Export เป็น Excel/CSV ใช้แทนได้ ผลเหมือนกัน

## ขั้นตอนที่ 3 — Deploy เว็บแอป

1. Apps Script → **Deploy → New deployment** → เลือกชนิด **Web app**
2. ตั้งค่า
   - **Execute as**: `Me`
   - **Who has access**: `Anyone`
3. กด **Deploy** แล้วก็อป **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

เปิด URL นี้บนมือถือเพื่อคีย์งาน แนะนำให้กด "เพิ่มลงในหน้าจอโฮม" (Add to Home Screen) จะได้เปิดเหมือนแอป

> แก้โค้ดทีหลังแล้วเว็บยังเป็นของเดิม ต้องกลับไปที่ **Deploy → Manage deployments → ไอคอนดินสอ → Version: New version → Deploy** ทุกครั้ง

---

## ขั้นตอนที่ 4 — ทดสอบ

1. เปิด Web app URL บนมือถือหรือคอม
2. เลือกเขต → เช็คว่าสาขาที่โผล่มาเป็นสาขาในเขตนั้นจริง ๆ
3. กรอกเลขที่ใบ PR + เลือกสาขา + เลือกขนส่ง + ใส่รายการอะไหล่ 1 ชิ้น → กดบันทึก
   → ต้องขึ้นเลขที่รอบส่ง (เช่น `WR-20260731-001`)
4. ลองบันทึกอีกรอบแบบติ๊ก "ฝากลงที่อื่น" (เช่น ปลายทางสาขาในเขตขอนแก่น แต่ฝากลงกันทรวิชัย)
   → ต้องขึ้นข้อความเตือนสีส้ม และรายการต้องขึ้น "ฝากลงที่ ..." ในรายงาน
5. กดแท็บ "รายงาน" ด้านบน → ค้นด้วยเลขที่ใบ PR หรือรหัสอะไหล่ที่เพิ่งคีย์ → ต้องเจอ

## การใช้งานประจำวัน

- **แนบรูปใบโอนย้าย (เร็วที่สุด)**: การ์ดบนสุดของฟอร์ม → เลือก/ถ่ายรูปใบโอนย้าย →
  กด **"อ่านข้อมูลจากรูป"** ระบบจะใช้ OCR อ่าน **เลขที่ใบ / วันที่ / สาขาปลายทาง /
  รายการอะไหล่** มาเติมในฟอร์มให้ แล้วเก็บรูปไว้ใน Google Drive เป็นหลักฐาน
  (อยากให้อ่านแม่นขึ้นอีก ตั้งค่า Cloud Vision ได้ ดูหัวข้อท้ายไฟล์)
  ฝั่งรายการอะไหล่ระบบจะเก็บมาแค่ **รหัสสินค้า / ชื่อสินค้า / จำนวน** เท่านั้น
  ซีเรียล สี ราคาขาย และยอดรวมถูกตัดทิ้งตั้งแต่ตอนอ่าน จะได้ไม่มีอะไรหลุดไปปนในชื่ออะไหล่
- **ระบบช่วยแก้จุดที่ OCR อ่านเพี้ยนให้ก่อน** โดยเทียบกับชีต `Parts`
  - รูปถ่ายจากมือถือที่ตะแคงอยู่ ถูกหมุนให้ถูกด้านก่อนส่งไปอ่าน
  - รูปที่ส่งไปอ่านเป็นคนละไฟล์กับรูปที่เก็บ — ตัวอ่านได้รูปคมกว่า (2400px ขาวดำ เร่งคอนทราสต์)
    ส่วนไดรฟ์เก็บรูปที่ย่อแล้วตามเดิม ไม่เปลืองที่
  - รหัสที่อ่านสลับ เช่น `O` เป็น `0`, `l` เป็น `1`, `S` เป็น `5` ระบบแปลงกลับให้
  - รหัสที่ OCR แทรกช่องว่างกลางคัน เช่น `บด 68000004` ก็ยังจับคู่ได้
  - รหัสอ่านไม่ได้เรื่องเลยแต่ชื่อสินค้าตรงกับในตารางแม่ ระบบกู้รหัสคืนจากชื่อให้
    (ยกเว้นชื่อที่ซ้ำกันหลายรหัส — เดาไม่ได้ก็ไม่เดา)
  - แถวไหนที่ระบบแก้รหัสให้ จะขึ้นกรอบส้มไว้และบอกจำนวนไว้ในสรุป ให้ดูอีกรอบก่อนบันทึก
  - อ่านรอบแรกแล้วไม่เจอรายการเลย ระบบจะลองเรนเดอร์รูปอีกแบบแล้วอ่านซ้ำให้เองหนึ่งครั้ง
- **ต้องติ๊กยืนยันก่อนบันทึกทุกครั้งที่ข้อมูลมาจากรูป**: เหนือรายการอะไหล่จะมีกล่องสีส้ม
  **"ตรวจรายการที่อ่านจากรูปแล้ว ถูกต้องครบทุกช่อง"** ยังไม่ติ๊กก็ยังกดบันทึกไม่ได้
  ช่องที่ OCR อ่านมาไม่ครบจะขึ้นกรอบสีส้มไว้ให้เห็นว่าต้องเติมตรงไหน
  และถ้าแถวไหนไม่ได้ใส่จำนวน ระบบจะฟ้องชื่อรายการนั้นให้ (ไม่เดาให้เป็น 1 เอง)
  รายการที่คีย์เองทั้งหมดไม่ต้องผ่านด่านนี้
  ในหน้าแนบหลายใบ แต่ละใบมีช่องติ๊กของตัวเอง หรือกด **"✔ ตรวจครบแล้วทุกใบ"** ทีเดียวก็ได้
- **เลือกรูปจาก Google Drive**: กด **"☁️ เลือกจาก Google Drive"** ใต้ปุ่มถ่ายรูป
  จะมีหน้าต่างขึ้นมาให้เดินดูโฟลเดอร์ ค้นชื่อไฟล์ และติ๊กเลือกได้ทีละหลายใบ
  ติ๊กใบเดียว = เข้าฟอร์มปกติ ติ๊กตั้งแต่ 2 ใบ = เด้งไปหน้าบันทึกหลายรายการเหมือนเลือกจากเครื่อง
  ในหน้าบันทึกหลายรายการก็มีปุ่ม **"☁️ แนบเพิ่มจาก Google Drive"** ให้แนบใบเพิ่มระหว่างทางได้
  รูปจากไดรฟ์เดินเส้นทางเดียวกับรูปจากเครื่องทุกอย่าง (ย่อรูป อ่าน OCR กันใบซ้ำ เก็บหลักฐาน)
  - **เห็นได้เฉพาะโฟลเดอร์เดียวที่กำหนดไว้** ครั้งแรกระบบสร้างโฟลเดอร์ชื่อ
    **"รูปใบโอนย้ายรอบันทึก"** ในไดรฟ์ให้ เอารูปไปวางในนั้น (จะแบ่งโฟลเดอร์ย่อยตามเดือนก็ได้)
  - อยากใช้โฟลเดอร์อื่น เช่นโฟลเดอร์ที่มือถือซิงก์รูปขึ้นไป ให้ใส่ id ของโฟลเดอร์นั้นใน
    Script Property ชื่อ `PICK_FOLDER_ID` (id คือส่วนท้าย URL ตอนเปิดโฟลเดอร์ในไดรฟ์)
  - **ทำไมต้องจำกัดแค่โฟลเดอร์เดียว**: เว็บแอปรันด้วยสิทธิ์ของเจ้าของสคริปต์ ไม่ใช่สิทธิ์ของคนเปิดลิงก์
    ถ้าเปิดให้เลือกได้ทั้งไดรฟ์ ทุกคนที่มีลิงก์เว็บแอปก็จะเปิดดูไดรฟ์ของเจ้าของได้ทั้งใบ
    ระบบจึงตรวจฝั่งเซิร์ฟเวอร์ทุกครั้งว่าไฟล์ที่ขอมาอยู่ในโฟลเดอร์นั้นจริง
    **อย่าเอาไฟล์ที่ไม่อยากให้คนอื่นเห็นไปวางในโฟลเดอร์นี้**
  - ไฟล์ใหญ่เกิน 15 MB จะไม่ยอมดึง ให้ย่อรูปก่อน
- **แนบหลายใบพร้อมกัน**: กด **"🖼️ เลือกรูป"** แล้วเลือกทีเดียวหลายใบ
  พอเลือกตั้งแต่ 2 ใบขึ้นไป ระบบจะเปิด**หน้าตรวจทีละใบ**ให้ — อ่านทุกใบเรียงกันไป
  แล้วแยกเป็นการ์ดละใบ **มีรูปของใบนั้นติดอยู่บนหัวการ์ด** (กดที่รูปเพื่อขยายดู)
  ตรวจเลขที่ใบ / สาขา / เขต / รายการอะไหล่ของแต่ละใบ แก้ตรงไหนก็ได้ ลบใบที่ไม่เอาออกได้
  แล้วกด **"บันทึกทั้งหมด"** ครั้งเดียว
  ระบบจะ**บันทึกแยกเป็นคนละรายการ** และเก็บรูปของใบนั้นคู่กับรายการนั้น
  วันที่ส่ง / ผู้บันทึก ใช้ร่วมกันทั้งชุด ไม่ต้องกรอกซ้ำทุกใบ
- **แต่ละใบไปคนละคันได้**: ในหน้าหลายใบ ทุกใบมีช่องขนส่งของตัวเอง
  ช่อง **"ขนส่ง / ผู้มารับของ"** ด้านบนคือตัวตั้งให้ทุกใบทีเดียว (จำคนล่าสุดที่ใช้มาให้ด้วย)
  ถ้าใบไหนไปคนละคัน แก้เฉพาะใบนั้นได้เลย ระบบจะบันทึกขนส่งของใครของมัน
  สาขาที่ตั้ง `defaultCarrier` ไว้ในชีต `Branches` จะถูกเติมให้เองด้วย ถ้ายังไม่ได้เลือกเอง
  ต้องการเพิ่มคนขนส่งกลางคัน กด **"+ เพิ่มคนขนส่ง / สาขามารับเอง"** ได้จากหน้านี้เลย
  ถ้าใบไหนบันทึกไม่ผ่าน ใบนั้นจะยังแก้ได้ กดบันทึกอีกครั้งจะยิงเฉพาะใบที่ค้าง ไม่บันทึกใบเดิมซ้ำ
- **กันบันทึกใบซ้ำ**: ระบบตรวจให้เอง 3 จุด
  1. **แนบไฟล์รูปเดิมซ้ำในชุดเดียวกัน** → ข้ามให้เลย ไม่เสียเวลาอ่านซ้ำ
  2. **รูปที่เคยแนบบันทึกไปแล้ว** → ทักตั้งแต่ตอนแนบ บอกว่าซ้ำกับรอบไหน (เทียบจากตัวไฟล์ ไม่ใช่ชื่อไฟล์)
  3. **เลขที่ใบ PR ซ้ำ** → จับได้แม้จะถ่ายใบเดิมใหม่เป็นคนละรูป

  ทั้งสามกรณี**ไม่ได้ห้ามขาด** — ถ้าเป็นการส่งคนละรอบจริง ๆ กดยืนยัน
  (ฟอร์มเดี่ยว) หรือติ๊ก "เป็นคนละรอบ บันทึกใบนี้ซ้ำอยู่ดี" (หน้าหลายใบ) แล้วบันทึกได้
  การตรวจอยู่ที่ฝั่งเซิร์ฟเวอร์ใต้ล็อกเดียวกับที่เขียนข้อมูล สองเครื่องกดพร้อมกันก็ไม่รอดไปทั้งคู่
- **คีย์งาน**: เปิดลิงก์เว็บแอป → กรอกเลขที่ใบ PR → เลือกเขต → เลือกสาขา (กรองมาให้แล้ว) →
  เลือกขนส่ง → ใส่รายการอะไหล่ → กดบันทึก
- **ใส่รายการอะไหล่**: พิมพ์รหัสสินค้าตั้งแต่ 2 ตัวอักษรขึ้นไป ระบบจะค้นจากชีต `Parts`
  แล้วเด้งรายการขึ้นมาให้เลือก พอเลือกแล้ว**ชื่อสินค้าจะถูกเติมให้อัตโนมัติ**
  (พิมพ์ชื่อสินค้าเพื่อค้นก็ได้)
- **ของที่เลิกใช้แล้ว**: ถ้าเลือกอะไหล่ที่ตั้งสถานะ `เลิกใช้` ไว้ จะมีแถบเตือนสีส้มขึ้นใต้แถวนั้น
  บอกว่าให้ใช้รหัสไหนแทน พร้อมปุ่ม **"เปลี่ยนให้"** กดครั้งเดียวสลับเป็นตัวใหม่ทั้งรหัสและชื่อ
- **อะไหล่ที่ยังไม่มีในตาราง**: พิมพ์รหัสกับชื่อเองแล้วบันทึกได้เลย
  ระบบจะ**เก็บอะไหล่ตัวนั้นเข้าชีต `Parts` ให้อัตโนมัติ** พร้อมหมายเหตุว่า
  "เพิ่มอัตโนมัติตอนบันทึกส่งของ" จะได้ตามไปตรวจ/แก้ชื่อทีหลังได้
- **จัดการอะไหล่**: แท็บ **"อะไหล่"** ด้านบน — ค้นหา เพิ่มใหม่ แก้ไขชื่อ
  ตั้งสถานะเลิกใช้พร้อมระบุรหัสที่ใช้แทน และใส่หมายเหตุได้ ทุกอย่างบันทึกลงชีต `Parts` โดยตรง
- **จัดการขนส่ง / ผู้มารับของ**: แท็บ **"ขนส่ง"** — ค้นหา (ด้วยชื่อ รหัส หรือเบอร์โทร)
  เพิ่มใหม่ แก้ไขเบอร์/หมายเหตุ และติ๊กออกเมื่อเลิกใช้ (จะหายจากตัวเลือกในฟอร์มบันทึก
  แต่ยังค้นเจอในหน้านี้ และรอบส่งเก่าที่ใช้ชื่อนี้ยังอยู่ครบ) บันทึกลงชีต `Carriers` โดยตรง
- **สาขามารับของเอง ไม่ผ่านขนส่งหลัก**: ในหน้าบันทึก กดปุ่ม
  **"+ เพิ่มคนขนส่ง / สาขามารับเอง"** ใต้ช่องขนส่ง กรอกชื่อ (กับเบอร์โทรถ้ามี) แล้วกด
  "เพิ่มแล้วใช้เลย" ระบบจะเพิ่มเข้าชีต `Carriers` และเลือกให้ทันที ไม่ต้องออกจากฟอร์ม
- **ฝากลงที่อื่น**: ติ๊กสวิตช์ "ฝากลงที่อื่น" แล้วเลือกจุดฝากลง (เลือกสาขาอื่นหรือจุดใน `DropPoints` ได้
  ถ้าไม่มีในลิสต์ เลือก "อื่น ๆ (พิมพ์เอง)")
- **ดูรายงาน**: แท็บ "รายงาน" ด้านบน — ค้นด้วยเลขที่ใบ PR / รหัสอะไหล่ / ชื่ออะไหล่ / เลขพัสดุ /
  จุดฝากลง กรองตามเขต สาขา ช่วงวันที่ หรือเฉพาะรายการที่ฝากลงที่อื่นได้
  รอบไหนที่แนบรูปไว้จะมีลิงก์ **"📎 ดูรูปใบโอนย้าย"** กดเปิดดูย้อนหลังได้
- **รายงานแยกตามวันจัดส่ง**: การ์ดถูกจัดกลุ่มเป็นวัน ๆ วันล่าสุดอยู่บนสุด
  หัวข้อของแต่ละวันบอก **จำนวนรอบส่ง** และ **จำนวนชิ้นรวมของวันนั้น**
  ส่วนแถบด้านบนสุดสรุปทั้งช่วงที่ค้น (กี่รอบ / กี่ชิ้น / กี่วัน)
  ยอดสรุปนับจากทุกแถวที่ตรงเงื่อนไข ต่อให้รายละเอียดถูกตัดเหลือ 200 รอบล่าสุดก็ยังนับครบ
- **ค้นหาในรายงาน**: พิมพ์**หลายคำคั่นด้วยเว้นวรรค**ได้ ต้องเจอครบทุกคำถึงจะนับว่าตรง
  เช่น `คง มอเตอร์` = ส่งไปสาขาคง และในรอบนั้นมีมอเตอร์
  มีปุ่มช่วงวันด่วน **วันนี้ / 7 วันล่าสุด / เดือนนี้ / ทุกวัน**
  เลือกเขตแล้วรายการสาขาจะเหลือเฉพาะเขตนั้น และค้นให้ทันทีที่เลือก
  เงื่อนไขที่ใช้อยู่จะขึ้นเป็นชิป กด **×** เอาออกทีละอันได้
  หรือกด **"ล้างการค้นหา"** เพื่อล้างทุกเงื่อนไขทีเดียว
- **ลบรายการในรายงาน**: การ์ดแต่ละใบมีปุ่ม **"🗑 ลบ"** กดแล้วจะมีกล่องยืนยันขึ้นในการ์ดนั้น
  บอกว่ากำลังจะลบรอบไหน ไปสาขาไหน และมีอะไหล่กี่รายการ กด **"ยืนยันลบ"** อีกครั้งถึงจะลบจริง
  - ลบทั้งแถวในชีต `Shipments` และรายการอะไหล่ของรอบนั้นในชีต `Items`
  - **รูปหลักฐานถูกย้ายไปถังขยะของไดรฟ์** (กู้คืนเองได้ภายใน 30 วัน)
  - ไม่แตะชีต `Parts` เพราะอะไหล่ที่เคยเพิ่มเข้าตารางแม่อาจถูกใช้ในรอบอื่นแล้ว
  - ลบแล้วเลขที่ใบนั้นกลับมาใช้บันทึกใหม่ได้ ระบบจะไม่ทักว่าซ้ำอีก
- **แก้ไขรายการที่บันทึกไปแล้ว**: ในหน้ารายงาน แต่ละรายการมีปุ่ม **"แก้ไขรายการนี้"**
  กดแล้วระบบจะพากลับไปที่ฟอร์มบันทึกพร้อมเติมค่าเดิมมาให้ครบ (เลขที่ใบ วันที่ เขต สาขา
  จุดฝากลง ขนส่ง เลขพัสดุ จำนวนกล่อง ผู้รับ หมายเหตุ และรายการอะไหล่ทุกแถว)
  แก้เสร็จกด **"บันทึกการแก้ไข"** ระบบจะเขียนทับรายการเดิม **ไม่สร้างรายการใหม่**
  - ใช้ฟอร์มเดิมทั้งหมด ช่องค้นอะไหล่ / เลือกเขต-สาขา / เพิ่มคนขนส่ง จึงทำงานเหมือนตอนคีย์งานปกติ
  - **ไม่แนบรูปใหม่ = รูปหลักฐานเดิมยังอยู่ครบ** ถ้าอยากเปลี่ยนรูป ให้แนบรูปใหม่ทับได้เลย
  - ระบบจดเวลาที่แก้และชื่อคนแก้ไว้ (คอลัมน์ `updatedAt` / `updatedBy`) แล้วโชว์บนการ์ดในรายงาน
  - ถ้าแก้เลขที่ใบไปชนกับรายการอื่น ระบบจะทักว่าซ้ำ (แต่ไม่นับว่าซ้ำกับตัวเอง)
  - กด **"ยกเลิกการแก้ไข"** เพื่อออกจากโหมดแก้ไขโดยไม่บันทึกอะไร
- **แก้ข้อมูลย้อนหลังจากในชีต**: แก้ในชีตได้ตรง ๆ เหมือนเดิม (ระบบไม่ล็อกอะไร) —
  ชีต `Shipments` คือ 1 แถวต่อ 1 รอบส่ง ส่วนรายการอะไหล่แต่ละชิ้นอยู่ในชีต `Items`
  ผูกกับ `shipmentId` เดียวกัน

## เรื่องที่ควรรู้

**กันบันทึกซ้ำ** มีสามชั้น ทำงานคนละหน้าที่กัน

| ชั้น | กันอะไร | ทำยังไง |
|---|---|---|
| token ประจำรอบ | เน็ตหลุดแล้วกดบันทึกซ้ำ / กดรัวสองที | ทุกครั้งที่เปิดฟอร์มจะมี token ประจำรอบ ถ้าซ้ำจะคืนรอบเดิมให้ ไม่เขียนแถวใหม่ |
| ลายนิ้วมือของรูป | แนบ**ไฟล์รูปเดิม**ซ้ำ | คิดจากตัวไฟล์ (MD5) เก็บในคอลัมน์ `slipHash` เปลี่ยนชื่อไฟล์ก็ยังจับได้ |
| เลขที่ใบ PR | **ถ่ายใบเดิมใหม่**เป็นคนละรูป | เทียบเลขที่ใบกับทุกรอบที่เคยบันทึก ไม่สนตัวพิมพ์ใหญ่เล็ก |

สองชั้นหลัง**บอกแล้วให้คนตัดสินใจ** ไม่ได้ห้ามขาด เพราะบางทีก็ส่งซ้ำจริง ๆ
การตรวจทำที่ฝั่งเซิร์ฟเวอร์ใต้ล็อกเดียวกับที่เขียนข้อมูล และลายนิ้วมือคิดจากรูปที่ส่งมาจริง
ไม่ได้เชื่อค่าที่หน้าเว็บส่งมา — สองเครื่องกดพร้อมกันจึงไม่รอดไปทั้งคู่

**รูปหลักฐานเก็บที่ไหน** ระบบสร้างโฟลเดอร์ชื่อ **"หลักฐานการส่งอะไหล่"** ใน Google Drive
ของบัญชีที่ deploy เว็บแอป แล้วเก็บรูปไว้ที่นั่น ตัวไฟล์**ไม่ได้แชร์เป็นสาธารณะ** — เวลากดดูรูป
เว็บแอปจะเป็นคนดึงมาแสดงให้ ชีต `Shipments` เก็บแค่ `slipFileId` ไว้อ้างอิง
ถ้าอยากดูไฟล์ทั้งหมด เปิด Drive แล้วเข้าโฟลเดอร์นั้นได้เลย
ลิงก์ดูรูป (`?img=<id>`) เสิร์ฟเฉพาะ id ที่มีอยู่จริงในชีต `Shipments` เท่านั้น
เดา id ของไฟล์อื่นในไดรฟ์แล้วเปิดผ่านเว็บแอปไม่ได้

**สิทธิ์ที่ต้องอนุญาตเพิ่ม** ฟีเจอร์อ่านรูปใช้ Google Drive จึงต้องอนุญาตสิทธิ์ Drive
ตอนรันครั้งแรกหลังอัปเดตโค้ด (จะมีหน้าขอสิทธิ์เด้งขึ้นมาอีกรอบ ให้กดอนุญาตตามเดิม)

**ไม่มีด่านรหัสผ่าน** เว็บแอปตั้งเป็น "Anyone" ใครมีลิงก์ก็เปิดกรอกได้ทันทีโดยไม่ต้องล็อกอิน
ถ้าอยากจำกัดคนใช้ทีหลัง เปลี่ยน deployment เป็น **Who has access: Anyone with Google account**
ได้ (แต่ทุกคนที่คีย์งานต้องมีบัญชี Google และล็อกอินก่อน)

## ทำให้ระบบอ่านใบแม่นขึ้นด้วย Cloud Vision (ไม่บังคับ)

ระบบอ่านใบได้สองทาง เลือกให้เองอัตโนมัติ

| ตัวอ่าน | ใช้เมื่อ | ความแม่น |
|---|---|---|
| **Drive OCR** | ค่าเริ่มต้น ไม่ต้องตั้งอะไรเลย | พออ่านได้ แต่ใบที่เป็นตารางแน่น ๆ หรือถ่ายเอียง มักอ่านคอลัมน์สลับ |
| **Cloud Vision** | เมื่อใส่ `VISION_API_KEY` | แม่นกว่าชัดเจน และคืน**ตำแหน่งของทุกคำ**มาให้ ระบบจึงประกอบบรรทัดใหม่ตามที่ตาเห็น คอลัมน์ไม่สลับ |

ถ้า Cloud Vision เรียกไม่ผ่าน (คีย์ผิด / เกินโควตา / เน็ตล่ม) ระบบจะ**ถอยไปใช้ Drive OCR ให้เอง**
ไม่ทำให้การอ่านใบล้มทั้งใบ และจะบอกไว้บนหน้าจอว่าใช้ตัวไหนอ่าน

**วิธีเอาคีย์มา**

1. เปิด https://console.cloud.google.com แล้วสร้างโปรเจกต์ (หรือใช้ที่มีอยู่)
2. เปิดใช้ **Cloud Vision API** ในโปรเจกต์นั้น (ค้นคำว่า Vision ใน Enable APIs)
3. เปิด **การเรียกเก็บเงิน (Billing)** ของโปรเจกต์ — Vision ให้ใช้ฟรีเดือนละ 1,000 ครั้ง
   ถ้าส่งวันละ 20-30 ใบก็ยังอยู่ในโควตาฟรี แต่ Google บังคับให้ผูกบัตรไว้ก่อนถึงจะเรียกได้
4. ไปที่ **APIs & Services → Credentials → Create credentials → API key** แล้วก็อปคีย์มา
5. **จำกัดคีย์ก่อนใช้เสมอ** — กด Edit ที่คีย์นั้น → API restrictions → เลือกเฉพาะ Cloud Vision API
   คีย์ที่ไม่จำกัดไว้ ถ้าหลุดออกไปจะถูกเอาไปใช้จนคิดเงินย้อนมาที่โปรเจกต์เรา
6. ใน Apps Script: **Project Settings → Script Properties → Add script property**
   ใส่ `VISION_API_KEY` = คีย์ที่ได้มา แล้วกดบันทึก
7. กลับมาที่หน้าโค้ด รันฟังก์ชัน `checkVisionKey()` หนึ่งครั้งเพื่อดูว่าคีย์ใช้ได้จริง

> เก็บคีย์ไว้ใน Script Properties เท่านั้น **อย่าพิมพ์ลงในโค้ด** เพราะโค้ดจะถูกก็อปไปมา
> ถ้าคีย์เคยหลุดออกไป ให้ไปลบคีย์เดิมทิ้งใน Cloud Console แล้วสร้างใหม่

## ฟังก์ชันที่รันเองได้จาก Apps Script

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `setupSheets()` | สร้าง/ซ่อมโครงสร้างชีต พร้อมข้อมูลสาขาจริง (รันซ้ำได้ ไม่ลบข้อมูลที่มีอยู่) |
| `checkSetup()` | ตรวจว่าแต่ละชีตมีข้อมูลกี่แถว และตอนนี้ใช้ตัวอ่านเอกสารตัวไหน |
| `checkVisionKey()` | ทดสอบว่าคีย์ Cloud Vision ใช้ได้จริง |
| `showWebAppUrl()` | ดู URL ของเว็บแอปที่ deploy ไว้ |

เมื่อสคริปต์ผูกกับชีต จะมีเมนู **"ระบบส่งอะไหล่"** บนแถบเมนูของชีต เรียกฟังก์ชันพวกนี้ได้เลย
(ถ้าเมนูไม่ขึ้น ให้รีเฟรชหน้าชีตหนึ่งครั้ง)

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| เปิดลิงก์แล้วขึ้น "ไม่พบชีต ..." | ยังไม่ได้รัน `setupSheets()` |
| ดรอปดาวน์ฟังก์ชันเห็นแค่ `myFunction` | โค้ดใน `Code.gs` วางไม่ครบหรือมีอักขระเพี้ยนจากการก็อปวาง ลองลบทั้งไฟล์ (Ctrl+A แล้วลบ) แล้ววางใหม่ทั้งไฟล์ จากนั้น Ctrl+S |
| แก้โค้ดแล้วเว็บยังเป็นของเดิม | ต้อง **Deploy → Manage deployments → แก้ไข → Version: New version** ทุกครั้ง |
| เพิ่ม/แก้สาขาในชีตแล้ว dropdown ยังไม่ขึ้น | ระบบแคชข้อมูลหลักไว้ 5 นาที รอสักครู่แล้วรีเฟรช หรือรัน `setupSheets()` เพื่อล้างแคช |

## สิ่งที่ยังไม่มีในเวอร์ชันนี้

ตามที่ตกลงไว้ เอาแค่ "บันทึก + ดูรายงาน" ให้เรียบง่ายที่สุดก่อน ยังไม่มี:

- การแจ้งเตือนอัตโนมัติ (เช่นเข้ากลุ่มไลน์) — เอาออกแล้วตามที่ขอ เพิ่มกลับได้ทีหลังถ้าต้องการ
- ด่านรหัสผ่านก่อนเข้าใช้งาน — เอาออกแล้วตามที่ขอ
- การยืนยันรับของจากปลายทาง
- การตัดสต็อกคลัง

โครงสร้างชีตออกแบบเผื่อไว้แล้ว เพิ่มคอลัมน์/ฟีเจอร์ทีหลังได้โดยไม่ต้องรื้อของเดิม
